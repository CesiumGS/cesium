Positioning with EXT_georeference

The extension declares the coordinate reference system of the node hierarchy. With ECEF (EPSG:4978), the root node's transform places the model on the globe directly.

No application-supplied model matrix is needed.

"extensions": {
  "EXT_geospatial_crs": {
    "format": "wkid",
    "extensions": {
      "EXT_geospatial_crs_wkid": {
        "authority": "EPSG",
        "wkid": 4978
      }
    }
  }
},
"nodes": [{
  "translation": [
    3687499.6, 3687499.6, 3659924.7
  ],
  "rotation": [
    0.176, 0.425, 0.820, 0.340

Extending glTF with 3DTILES_tileset_vectors

HydroRIVERS network streamed as vector tiles and draped on terrain. Lines are styled by the ORD_FLOW property. 

Cesium3DTileset.fromIonAssetId(5135960, {
  heightReference:
    HeightReference.CLAMP_TO_TERRAIN,
  scene,
});

tileset.style = new Cesium3DTileStyle({
  color: { conditions: [
    ["Number(${ORD_FLOW}) <= 1", "color('navy')"],
    ...
  ]},
  lineWidth:
    "5.0 - clamp(Number(${ORD_FLOW}), 0.0, 10.0) * 0.4",
});

True 3D vector data

3DTILES_tileset_vectors carries full 3D positions, so lines are placed in space rather than draped on terrain. 

const mesh =
  await Cesium3DTileset.fromIonAssetId(5135767);
const vectors =
  await Cesium3DTileset.fromIonAssetId(5135764);

vectors.style = new Cesium3DTileStyle({
  color: "color('cyan')",
  lineWidth: 3,
});

Voxels with EXT_voxels

A volumetric dataset rendered with a custom shader on the dvs metadata property. The globe is translucent and clipped so the volume is visible below the surface. 

float dvs = fsInput.metadata.dvs;
if (dvs < u_dvsMin || dvs > u_dvsMax) {
  material.alpha = 0.0;
  return;
}
float alpha = clamp(abs(dvs) / 3.0, 0.0, 1.0);
float thickness =
  fsInput.voxel.travelDistance / 50000.0;
material.alpha =
  1.0 - pow(1.0 - alpha * alpha, thickness);
