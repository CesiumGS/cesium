AGI HQ as an implicit octree. One root node describes the whole tree with URI templates and subtree availability files.

  "subdivisionScheme": "OCTREE",
  "availableLevels": 6,

    "tiles/{level}/{right}/{forward}/{up}.gltf",
  "subtreeUri":
    "subtrees/{level}/{right}/{forward}/{up}.subtree.glb"
}

Positioning with EXT_georeference

Longitude, latitude and height, with local axes aligned to east, up and north. Simpler than a 3D Tiles 1.1 transform matrix, and available to any glTF. 

"nodes": [{
  "mesh": 0,
  "rotation": [0, -0.173648, 0, 0.984807],
  "extensions": {
    "EXT_georeference": {
      "longitude": -75.158364,
      "latitude": 39.950907,
      "height": -21.67
    }
  }
}]

Model and axes are not to scale.

New in 3D Tiles 2.0

Extending glTF with 3DTILES_tileset_vectors

HydroRIVERS streamed as vector tiles, draped on terrain and styled by the ORD_FLOW property. 

const rivers = await Cesium3DTileset
  .fromIonAssetId(5135960, {
    heightReference:
      HeightReference.CLAMP_TO_TERRAIN,
    scene,
  });

rivers.style = new Cesium3DTileStyle({
  color: { conditions: [
    ["Number(${ORD_FLOW}) <= 1",
      "color('navy')"],
    ...
  ]},
});

New in 3D Tiles 2.0

True 3D vector data

3DTILES_tileset_vectors carries full 3D positions, so lines are placed in space rather than draped on terrain. 

const mesh = await Cesium3DTileset
  .fromIonAssetId(5135767);
const vectors = await Cesium3DTileset
  .fromIonAssetId(5135764);

vectors.style = new Cesium3DTileStyle({
  color: "color('cyan')",
  lineWidth: 3,
});

New in 3D Tiles 2.0

Voxels with EXT_voxels

Mantle velocity anomalies inverted from earthquake data, colored by a custom shader on the dvs property. 

float dvs = fsInput.metadata.dvs;
if (dvs < u_dvsMin || dvs > u_dvsMax) {
  material.alpha = 0.0;
  return;
}
float alpha = clamp(abs(dvs) / 3.0, 0.0, 1.0);
float thickness =
  fsInput.voxel.travelDistance / 50000.0;
material.alpha =
  1.0 - pow(1.0 - alpha * alpha, thickness);
