## Summary

1.x's new Sandcastle (`packages/sandcastle`, React on StrataKit) becomes 2.0's gallery; Dyno stays the development harness. Its examples are the migration corpus: each is moved with the agent kit and checked against 1.x, giving the gallery, proof of the kit, a measure of what 1.x code uses, and eval data.
