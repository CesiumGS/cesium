GPU check

Checks a WebGPU engine on an unfamiliar GPU. Reason: Intel reports a hang with indirect draws on UHD 7xx and Iris Xe graphics under Windows 11 (article 000102979, with DXGI_ERROR_DEVICE_REMOVED).

Read first. A real hang can reset the graphics driver for every app on this machine, and may freeze the screen for a few seconds. Save your other work first. Steps run one at a time, each from a click, smallest first. If the device is lost the run stops: nothing retries and nothing starts by itself. Reload the page to start again.
