Performance baselines: CesiumJS 1.x vs 2.0 PoC

Matched workloads on both engines: N independent flat-colored boxes (one draw each, like tile contents), picking, log depth, time to first frame, and four views. 1.x API calls are counted on the WebGL2 context; 2.0 calls on the WebGPU encoders and queue. "frame incl. GPU" waits for the GPU (gl.finish / onSubmittedWorkDone).

open with the runner, or call runBaseline() in the console
