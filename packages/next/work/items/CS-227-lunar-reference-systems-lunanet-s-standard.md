## Waiting on

No lunar 3D CRS or height system is standardized yet: NASA's LunaNet Lunar Reference System Standard (a public v1 was scheduled for November 2026, unconfirmed), the International Lunar Reference System's first realization ILuRF2026, and the IAG/IAU working group's lunar height system. Checked before 5g builds the lunar antenna's site grid; when one is adopted it joins the frame tree beside MOON_ME and MOON_PA. Sources: `docs/superpowers/specs/2026-11-07-frames-5-earth-to-moon-design.md`, section 18; `docs/design/bodies-frames-and-engineering-coordinates.md`, "Watch: lunar reference systems".
