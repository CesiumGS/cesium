# Work items

Cesium 2.0's work, one file per item: work, decisions waiting on someone, and dependencies outside our control, grouped into projects and initiatives. The format, lifecycle and rules are in [the tracker's design](../../../docs/superpowers/plans/2026-11-13-work-tracker.md); how to use it day to day is in [AGENTS.md](../AGENTS.md), "Work items".

- `initiatives/`: goals that group projects.
- `projects/`: one deliverable each, usually a plan in `docs/superpowers/plans/`.
- `items/`: work, decision and external items. Each names its project, and what it `needs`.

Common views, from `packages/next`:

```sh
node scripts/work/views.mjs ready        # what can start now
node scripts/work/views.mjs claims       # what other sessions have claimed
node scripts/work/views.mjs decisions    # what waits on the owner
node scripts/work/views.mjs check        # run before committing item changes
```

**Wave C: after CS-33, in parallel by area.**

**Wave D: after its inputs.** CS-75 (OpenPBR tier 1) after CS-121, since both edit `surface.slang`. CS-122 after CS-121. CS-34 and CS-35 after CS-33 (CS-35 also after CS-21). CS-135 and CS-138 after CS-134. The worker-mode façade's milestones once its plan is reviewed.
