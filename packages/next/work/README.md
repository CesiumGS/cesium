# Work items

Cesium 2.0's work, one file per entity: work, decisions waiting on someone, and dependencies outside our control, grouped into projects, with milestones as the outcomes they reach. The files are in human-in-the-lead's format, with its `hitld` commands; how to use them day to day is in [AGENTS.md](../AGENTS.md), "Work items", and the tracker's history in [its design](../../../docs/superpowers/plans/2026-11-13-work-tracker.md).

- `projects/`: one deliverable each, usually a plan in `docs/superpowers/plans/`.
- `milestones/`: checkable outcomes, each under a project. A milestone with no project is a long outcome, over the milestones it names as constraints.
- `items/`: work, decision and external items. Each names its project, and what it `needs`.
- `views/`: generated by `hitld work views` after merges; don't edit by hand.

Common views, from anywhere in the repository:

```sh
npx hitld work query --ready    # what can start now
npx hitld work claims           # what other sessions have claimed
npx hitld work query --kind decision --state planned   # what waits on the owner
npx hitld work check            # run before committing item changes
```
