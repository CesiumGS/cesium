## Summary

The public API reviews, one milestone each. Each review follows one pattern: its inputs (the surface map and checks), the review's proposals (CS-102 for the first), the owner's decision on which to approve, then the approved changes. Work elsewhere that must wait for the API's shape needs the owner's decision, not the review itself.

The first review (CS-420) takes CS-101's protocol table, from the worker-mode façade (CS-13), as its map of the surface; the façade's reshaping (CS-103 to CS-107) follows the approved changes.
