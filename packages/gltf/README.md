[CesiumJS](../../README.md) is a JavaScript library for creating 3D globes and 2D maps in a web browser without a plugin.

`@cesium/gltf` contains CesiumJS's glTF parsing and transformation utilities, independent of Cesium rendering and resource loading code.

## Install

`@cesium/gltf` is published as ES modules with full typing support.

Install with npm:

```sh
npm install @cesium/gltf --save
```

Or, install with yarn:

```sh
yarn add @cesium/gltf
```
